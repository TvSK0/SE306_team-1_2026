# Code metrics baseline ("before")

Recorded on 23 October 2026 from `main` at `ff950b2` (after #49), with CK 0.7.0 over `src/main/java/lavs`.
Re-run with `./mvnw -Pmetrics validate` (from `mainframe-interface-main`); the raw numbers are written to
`target/metrics/class.csv` and `method.csv`. The final report compares a re-run at the end against this.

- **Coupling:** CBO, the number of other classes a class uses. Lower is better.
- **Complexity:** WMC, the sum of the cyclomatic complexity of a class's methods, and the cyclomatic
  complexity of each method. The plan's target is no method over 10.
- **Cohesion:** LCOM*, from 0 (every method uses the same fields) to 1 (no shared fields). Lower is better.
